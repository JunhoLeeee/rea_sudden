# 로컬 연습 프로토타입의 규칙

이 문서의 수치는 `client_core/practice.py`에 직접 정의한 연습용 설계다.
원본 `serverbutes.txt`의 선언 수치를 단위 변환한 결과나 원본 물리 엔진 재현이라고 해석하지 않는다.

| 항목 | 연습용 값 |
|---|---|
| 좌표 | 미터, z 위쪽, yaw=0은 +x |
| 맵 | 직접 작성한 16×12 그리드, 셀 2m, 벽 높이 3m |
| 플레이어 반경 | 0.24m, 수평 원과 벽 박스 충돌, 축별 미끄러짐 |
| 달리기 / 걷기 / 앉기 | 3.3 / 2.0 / 1.4 m/s, 대각 속도 정규화 |
| 서기 / 앉기 눈높이 | 1.55 / 1.0m |
| 점프 속도 / 중력 | 5m/s / 12m/s², 착지 후 새 입력 필요 |
| 시간 처리 | 최대 0.1초 따라잡기, 내부 간격 최대 1/120초 |
| 시점 | 수직 화각 70도, pitch ±0.85rad, 마우스 0.002rad/픽셀 |
| 목표 | 제한 90초, 표적 10회 처치 |
| 표적 | 체력 100, 크기 0.64×0.64×1.85m, 머리 영역 z≥1.4m |
| 재등장 | 처치 후 2초 |
| 명중 | 조준 중심 광선, 벽과 표적 중 가장 가까운 교차, 최대 100m |

| 무기 | 탄창 / 예비탄 | 몸통 피해 | 머리 배율 | 발사 간격 | 재장전 | 발사 후 pitch 증가 |
|---|---|---|---|---|---|---|
| 소총 | 30 / 90 | 34 | 3배 | 0.105초 | 1.8초 | 0.009rad |
| 권총 | 7 / 35 | 55 | 3배 | 0.3초 | 1.25초 | 0.018rad |

두 무기 모두 버튼 유지 시 발사한다. 재장전 중에는 발사하지 못하고, 무기를 바꾸면 진행 중인
재장전을 취소한다. 빈 탄창에서 사격을 시도하면 예비탄이 있을 때 자동 재장전한다.
반동의 자동 복귀·탄 퍼짐·관통·거리 감쇠는 없다. 표적은 플레이어를 공격하지 않는다.

원본 관찰을 재사용한 부분은 `GameplaySettings.txt`의 HitMarker 프로필과
`client_core/hitmarker.py`의 정적 코드 기반 표시 모델이다. 브라우저 Canvas가 회전과 알파 합성을 수행한다.
GPU 픽셀 결과, 명중 판정, 게임 상태 게이트가 원본과 동일하다는 의미는 아니다.

서버는 루프백의 임의 포트에서 단일 연습 세션을 제공한다. 브라우저가 입력을 전송하며
Python이 이동·탄약·명중 결과를 결정한다. 탭/창 비활성화 또는 요청 간격 0.5초 초과 시 정지한다.
서버를 종료하면 진행 기록이 사라진다. 사운드와 원본 리소스 모델 재생은 아직 구현하지 않았다.
