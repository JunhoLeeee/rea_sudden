//	[Move]
//	Precision	= (도착포인트까지의 정확도)
//	Move3D		= (이동을 3D로 해야 할 경우)
//	Dir3D		= (방향을 3D로 바라봐야 할 경우)
//	PathFinder	= (웨이포인터를 사용하여 길찾기여부)
//	Offset		= (x,y,z)
//	InstabilityTime	= (이동불안정시간)
//	InstabilityFactor= (이동불안정시간)
//	SuicideTime	= (몇초간 못움직일때 자살)
//	Axis		= (x,y,z,f)

//	[Combat]
//	DetectMin	= (타겟발견할 수 있는 최소 범위)
//	DetectMax	= (타겟발견할 수 있는 최대 범위)
//	Fire		= (0 or 1)
//	Delay		= (타겟 발견후 공격까지의 지연시간)
//	Action		= (stop, path or dynamic [default = stop])

//	[Event0~]
//	ID		= (이벤트넘버)
//	State		= (Move, Combat0 or Combat1)
//	TargetType	= (Rand , Sequence [default = rand])
//	Target		= (목적지 Tag or FindType[NearAlly, NearEnemy, NearNeutral, FarAlly, FarEnemy, FarNeutral], ...)
//	TargetDetail	= (범위, 각도)
//	Via		= (경유할 수 있는 Tag, ...)
//	Delay		= (도착후 딜레이 시간, ...)
//	NextID		= (다음이벤트넘버, ...)
//	Command		= (미리정해진공백없는알파벳[$, REMOVE, FIRE0, FIRE1], ...)
//	'...'이 찍혀 있는 것은 ','를 이용하여 여러개를 사용할 수 있다는 뜻이며
//	여러개를 사용했을 시 그 이벤트가 발생할때 랜덤하게 하나를 선택한다.
//	단, Target의 경우 TargetType을 sequence로 해 놓으면 순차적으로 선택하는것도 가능하다.
