**  1) All definition properties (i.e., [Debris0]) ARE case sensitive.
**	   If you are adding a new definition, it is best to start with a
**     copy of an existing (working) definition.
**	2) Name properties are NOT case sensitive (i.e., Name = "Joe" is the same
**	   as Name = "JOE")
**  3) All time is specified in seconds (unless otherwise noted)
**  4) The Float type is the same as Real (i.e., 1.0 or 1.5)
**  5) The valid range of all RGB color properties is between
**     0 and 255 (e.g., (0, 255, 0) would be green).
**
*/


/************************************************************************
**
** DEBRIS
**
** The Debris definitions define all of the attributes associated with
** a particular debris type.  These definitions *usually* map directly to
** a particular surface type (see Surface.txt).  However, there may be
** multiple debris types that map to the same surface (e.g., light wood,
** heavy wood, etc.)
**
**
** All debris definitions should contain the following properties:
**
**  Name (String)
**
**      The user friendly name of the debris type (what shows up in DEdit).
**
**	SurfaceId (Integer)
**
**		This should map directly to a surface id (specified in Surface.txt).
**		For example, SurfaceId = 0 maps to ST_UNKNOWN.
**
**	MinScale (Float)
**
**		A random value between MinScale and MaxScale is used to scale the
**		debris models.
**
**	MaxScale (Float)
**
**		A random value between MinScale and MaxScale is used to scale the
**		debris models.
**
**	MinVel (Vector)
**
**		The minimum velocity of the debris.  The x/z components should be the
**		same value, the y component is along the forward vector of the direction
**		the debris will move (a positive value is away from the direction of
**		damage).  A random value between MinVel and MaxVel is used for the
**		velocity of each debris piece.
**
**	MinDebrisOffset (Vector)
**
**		The minimum offset (from the origin of the debris) where each
**		debris item is created.  A random value between MinDebrisOffset
**		and MinDebrisOffset is assigned to each debris.  NOTE:  The offsets
**		are in world coordinates, so the x and z components of the vector
**		should always be the same (unless you want the fx to always align
**		to a world axis).
**
**	MaxDebrisOffset (Vector)
**
**		The minimum offset (from the origin of the debris) where each
**		debris item is created.  A random value between MinDebrisOffset
**		and MinDebrisOffset is assigned to each debris.  NOTE:  The offsets
**		are in world coordinates, so the x and z components of the vector
**		should always be the same (unless you want the fx to always align
**		to a world axis).
**
**	MaxVel (Vector)
**
**		The maximum velocity of the debris.  The x/z components should be the
**		same value, the y component is along the forward vector of the direction
**		the debris will move (a positive value is away from the direction of
**		damage).  A random value between MinVel and MaxVel is used for the
**		velocity of each debris piece.
**
**	MinLifetime (Float)
**
**		Each debris model lives for a random time between MinLifetime and
**		MaxLifetime + Fadetime.
**			Lifetime = Random(MinLifetime, MaxLifetime) + Fadetime).
**
**	MaxLifetime (Float)
**
**		Each debris model lives for a random time between MinLifetime and
**		MaxLifetime + Fadetime.
**			Lifetime = Random(MinLifetime, MaxLifetime) + Fadetime).
**
**	Fadetime (Float)
**
**		How long it takes the debris to fade away.
**			Lifetime = Random(MinLifetime, MaxLifetime) + Fadetime).
**
**	Number (Integer)
**
**		The number of debris pieces.  NOTE:  You can't have more than 20 debris
**		pieces.
**
**	Rotate (Integer)
**
**		Should the debris rotate as it flies through the air (0=false, 1=true).
**
**	MinBounce (Integer)
**
**		Minimum number of times that each debris piece will bounce (a random
**		value between MinBounce and MaxBounce will be used for each piece).
**
**	MaxBounce (Integer)
**
**		Maximum number of times that each debris piece will bounce (a random
**		value between MinBounce and MaxBounce will be used for each piece).
**
**	GravityScale (Float)
**
**		How much the current gravity value (normal or underwater) affects the
**		debris (1.0 is normal 0.5 is half gravity, etc.)
**
**	Alpha (Float)
**
**		The alpha value for the debris models (0.0 - 1.0)
**
**	Model1-10 (String)
**
**		Specifies the name of the debris model(s) to create.  Up to 10 models
**		may be specified (Only 1 model is necessary).  For example:
**
**			Model1	= "SFX\Debris\Models\generic1.abc"
**			Model2	= "SFX\Debris\Models\generic2.abc"
**		
**  Skin0-N (String)
**
**		The name of the model(s) skin(s).  All the models must use the same skins.
**      There can be any number of skins: Skin0, Skin1, ..., SkinN
**
**  RenderStyle0-N (String)
**
**		The name of the model(s) render style(s).  All the models must use the same render styles.
**      There can be any number of render styles: RenderStyle0, RenderStyle1, ..., RenderStyleN
**
**	BounceSnd1-2 (String) (OPTIONAL)
**
**		Name of the optional debris bounce sounds (sound played when the debris
**		hits a surface).  Up to 2 sounds may be specified.
**
**	ExplodeSnd1-2 (String) (OPTIONAL)
**
**		Name of the optional debris explode sounds (sound played when the debris
**		is first created).  Up to 2 sounds may be specified.
**
**
**  MinWorldVel (Vector) (OPTIONAL)
**  MaxWorldVel (Vector) (OPTIONAL)
**
**		When these are specified, it will add a random velocity between the minimum and
**		maximum values to be added to the debris in world space. This can be useful for
**		such things as making debris pop up into the air, which could be done like:
**		MinWorldVel = 0, 50, 0, and MaxWorldVel = 0, 100, 0
**
**	WorldSpaceFX (String) (OPTIONAL)
**
**		This can be used to name a client FX that will be played at the debris location in
**		world space. This allows for playing of effects that need to be independant of the
**		direction that the object was shot from (such as flour spraying into the air)
**
**	ImpactSpaceFX (String) (OPTIONAL)
**
**		This can be used to name a client FX that will be played at the debris location with
**		the orientation aligned to the impact that created the debris. This can be used to
**		do things like create effects that explode out in the direction that the object was
**		shot.
**		
*/
